# Game Ideas (WIP)

## Project Overview
**Title:** *Protocol: Celestial Overdrive*  
**Genre:** Alien Shooter FPS with puzzles and quests  
**Platform:** Roblox

This project is an original FPS game built **without templates**, focused on custom mechanics, progression systems, persistent data, and clean UI design.

---

## Core Goals
The game will include:
- Custom gameplay mechanics
- Player progression (XP, ranks, badges)
- Persistent data saving
- Simple but functional UI systems

---

## Core Concept
*Protocol: Celestial Overdrive* is a fast-paced FPS experience where players complete combat encounters, puzzles, and quests while progressing through a ranked system. Gameplay rewards movement mastery, combat skill, and system understanding.

---

## Systems to Implement

---

### 1. Custom Mechanics
- **FPS Combat System**  
  Core shooting mechanics designed for both PC and mobile players.

- **Atmospheric Hazards**  
  Certain areas require oxygen management and recovery.

- **Aim Assist (Mobile Only)**  
  Light aim assistance for mobile players (no auto-shooting).

- **Redshift Rage Mode**  
  Activated when health is low:
  - Increased fire rate  
  - Temporary combat buffs

- **Healing System**
  Medkit that recovers 10% of health (has a 30 second cooldown).

- **Kinetic Aero Dash**  
  Directional lunge ability:
  - Moves in the direction the player is facing  
  - Deals damage on impact

---

### 2. Player Progression

#### Rank System (Color-Coded)
- Rank 1–10: **Static Recruit**
- Rank 11–20: **Kinetic Specialist**
- Rank 21–30: **Orbital Sentinel**
- Rank 31–40: **Plasma Captain**
- Rank 41–50: **Nova Commander**
- Rank 51–60: **Stellar Warden**
- Rank 61–70: **Zenith Striker**
- Rank 71–80: **Celestial Vanguard**
- Rank 81–90: **Overdrive Archon**
- Rank 91–100: **Protocol Master**

- XP earned through gameplay
- Rank benefits unlock abilities, bonuses, or access
- Badges awarded for progression milestones

---

### Stats & Economy
- **Wins**
- **Plasma (Currency)**
  - Used to purchase weapons or melee upgrades

---

### Training Systems
- Bot practice modes
- Player vs Player (1v1) training

---

### 3. Persistent Data Saving
The following player data will be saved:
- Player level and rank
- Quest progress
- Inventory items
- Leaderstats (wins, plasma)

---

### 4. User Interface (UI)
- Quest tracking screen
- Mobile ability buttons
- Shop interface

---

## Development Approach
- Build one system at a time
- Test each system independently
- Prioritize stability before adding content
- Focus on clean, readable Lua code
